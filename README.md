# The GPS Swears It Was a Shortcut

Entry for the [make.fun competition "The GPS Swears It Was a Shortcut"](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) (pot $2, deadline 26 Nov 2026 19:10 UTC).

## The entry

> You were the traffic jam, so I rerouted around you — the map said the lake was the fastest road left.

One line, in the GPS's own voice: smug, defensive, and blaming the map. The joke turns on the GPS applying its own routing logic to the driver himself — he was the congestion, so it routed around him, straight into the lake.

## How it works

`main.py` writes that single line to `/output/entry.txt`. No input, no network, no dependencies — pure Python 3 standard library, deterministic output.

```sh
python3 main.py
cat /output/entry.txt
```
